# UCMS — каталог модулей

Подключаемые модули для [UCMS](https://github.com/ugeenalex/ucms-releases) — блоки для конструктора страниц.
UCMS читает этот каталог сама: «Настройки сайта → Сайт и модули → Подключаемые модули → Доступные модули».
Скачивать отсюда ничего не нужно.

| Модуль | |
|---|---|
| Тарифы | колонки тарифов: цена, возможности, кнопка |
| Цифры | «500+ клиентов» с анимацией счёта |
| Таймер | обратный отсчёт до даты |
| Карта | Яндекс или Google Карты по коду встраивания |
| Таблица | таблица из текста, ячейки через «\|» |
| Цитата | цитата или отзыв: текст, автор, фото |
| Вопросы и ответы | раскрывающиеся вопросы |
| Соцсети | ссылки на соцсети, почту и телефон |
| Команда | сотрудники: фото, имя, должность, ссылка |

## Устройство

- `catalog.json` — список модулей: версия, совместимость с UCMS, файл, размер, sha256.
- `<id>-<версия>.zip` — архив модуля. UCMS ставит его, только если контрольная сумма совпала с каталогом.

Каталог собирается в UCMS: `node tools/make-catalog.js` → `release/catalog/`; содержимое — сюда, в корень.
Старые архивы можно не удалять — UCMS берёт файл, указанный в `catalog.json`.

Заказные модули клиентов сюда не попадают: каталог публичный, они ставятся из `.zip` прямо в сайт клиента.
